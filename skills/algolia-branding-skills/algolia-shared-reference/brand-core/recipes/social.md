# recipe: social — Algolia social posts

output: platform-optimized post variants
mode: create or rebrand
platforms: LinkedIn, X (Twitter), or both

## inputs
topic to promote (launch | blog | event | customer win | thought-leadership | hiring) ·
target platform(s) · key takeaway · link (if any) · visual asset description (if any) · campaign/hashtag context

## structure
1. message extraction — identify the single most compelling takeaway; lead with value, not an announcement
2. LinkedIn post — 100–200 words; strong opening line visible before "see more"; line breaks for readability; one clear CTA; 3–5 hashtags; professional/insight-driven; "we" for company, first-person for exec thought-leadership
3. X post — under 260 chars (leave room for link); lead with the sharpest insight/stat; direct, punchy; 1–2 hashtags. If it needs more room, a 3–5 tweet thread outline (numbered 1/5…)
4. hashtag strategy — primary #Algolia on company posts; secondary topic tags (#AISearch, #SearchExperience, #Ecommerce, #DevTools, #SiteSearch); no irrelevant trending tags
5. visual guidance — describe the ideal accompanying visual (product screenshot | data viz | quote card | custom graphic); specify brand-core colors for any designed asset
6. engagement — LinkedIn: a question or poll suggestion; X: a hook inviting reply/RT
7. variants — 2–3 per platform for A/B (data-led, story-led, question-led)

## format-specific checks
opening line earns the "see more" cut · every stat sourced (approved-stats.md) · product names correct

## then
engine runs algolia-brand-check on all variants; fix to ≥8.
